Setup (prompt)

Review this prototype and produce: 1. the intended user outcome, 2. the edge cases, 3. a starter implementation outline, 4. open feasibility questions, and 5. a first-pass PR checklist.

Handoff removed

Reduces the wait between design review and engineering kickoff by turning a prototype into a more implementation-ready handoff.

Limitations

It does not replace technical design review or guarantee the right architecture.
